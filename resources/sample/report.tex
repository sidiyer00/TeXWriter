\section{How this example works}\label{sec:how}
This document is written in TeXWriter, but its tables and its figure are not typed by hand.
Each one is a \emph{generated} block: TeXWriter runs a script, reads the file the script
writes, and turns it into LaTeX. Press \textbf{Run all} in the toolbar (or Run on a single
block) to produce them; until then they show a placeholder.

\begin{itemize}
  \item \autoref{tab:coefficients} comes from \texttt{scripts/fit\_model.py}, which fits a
  linear model and writes a CSV file.
  \item \autoref{fig:fit} comes from \texttt{scripts/plot\_fit.py}, which saves a PDF with
  matplotlib.
  \item \autoref{tab:holdout} has no script: it reads \texttt{data/holdout\_metrics.csv},
  a file another program (here, a scoring job) keeps up to date. Edit the file and the table
  follows.
\end{itemize}

Add your own with Insert, Generated table or Generated figure, or from the Generated tab on
the left. Each block is paired with a script and the file it writes; its properties set the
caption, label, table style and number format.

\section{Model}\label{sec:model}
The response $y$ is modelled as a linear function of two predictors,
\begin{equation}\label{eq:model}
  y_i = \beta_0 + \beta_1 x_{1i} + \beta_2 x_{2i} + \varepsilon_i ,
\end{equation}
estimated by ordinary least squares on the training sample \citep{hastie2009}.

\section{Performance}\label{sec:performance}
Accuracy is measured on the holdout sample with the root mean squared error,
\begin{equation}\label{eq:rmse}
  \mathrm{RMSE} = \sqrt{\frac{1}{n}\sum_{i=1}^{n} \left(y_i - \hat{y}_i\right)^2} .
\end{equation}
Fitted and observed values on the holdout sample line up around the diagonal
(\autoref{fig:fit}), and the error in \eqref{eq:rmse} is close to the noise level.

\section{Writing a generator script}\label{app:script}
A script only has to write one file: a CSV (or a LaTeX tabular) for a table, a PDF or PNG for
a figure. TeXWriter passes the path in the \texttt{TEXWRITER\_OUTPUT} environment variable
and runs the script with the project folder as the working directory.

\begin{lstlisting}[language=Python]
import csv, os

rows = [["Model", "RMSE"], ["Linear", 1.04], ["Mean only", 2.31]]
with open(os.environ["TEXWRITER_OUTPUT"], "w", newline="") as f:
    csv.writer(f).writerows(rows)
\end{lstlisting}
